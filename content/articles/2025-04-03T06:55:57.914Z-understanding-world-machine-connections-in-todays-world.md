## 4. World-Machine Data Transfer: Optimizing for Quality and Performance

Efficient World-Machine data transfer is crucial for maintaining detail and minimizing performance bottlenecks. Here are some key considerations:

*   **Heightmap Resolution:** Higher resolution heightmaps capture more detail but require more memory and processing power. Find the right balance between visual fidelity and performance. Consider using tiled heightmaps for very large terrains.
*   **File Formats:** 16-bit PNG is generally recommended for heightmaps as it preserves detail and avoids banding artifacts. For other textures, consider using compressed formats like JPEG or PNG to reduce file sizes.
*   **Coordinate Systems:** Ensure that the coordinate systems in World-Machine and your target software are aligned. This will prevent unexpected distortions or scaling issues during import.
*   **Level of Detail (LOD):** Implement LOD techniques to reduce the complexity of the terrain as the camera moves further away. This can significantly improve performance, especially in game engines.
*   **Tiling:** For extremely large terrains, consider dividing the terrain into tiles. This allows you to load and render only the tiles that are currently visible, reducing memory usage and improving performance.

> **EXPERT TIP:** Experiment with different export settings and file formats to find the optimal balance between quality and performance for your specific project.
