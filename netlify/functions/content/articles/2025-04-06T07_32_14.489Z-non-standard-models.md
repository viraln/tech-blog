## 2. The Genesis of Non-Standard Analysis

Non-standard analysis, the framework within which non-standard models become truly useful, was pioneered by Abraham Robinson in the 1960s. Robinson's groundbreaking work demonstrated that it was possible to rigorously define infinitesimals, something that had been a source of debate and controversy in mathematics for centuries.

Before Robinson, mathematicians often relied on intuitive but imprecise notions of infinitesimals in calculus. Robinson provided a solid logical foundation, showing that these intuitive ideas could be made rigorous using the tools of mathematical logic and model theory. His approach involved constructing a non-standard model of the real numbers, denoted as *R* (often with an asterisk, *R*), which contains both the standard real numbers (R) and infinitesimals.

## 4. Exploring Non-Standard Model Examples: A Practical Guide

Let's look at a practical example. Consider the statement "Every number has a successor." In the standard model of natural numbers, this is obviously true. In a non-standard model, it's also true, but the "successor" of an infinite integer will also be an infinite integer.

Another example involves limits. In standard analysis, limits are defined using epsilon-delta arguments, which can be quite complex. In non-standard analysis, the limit of a sequence can be defined more intuitively: the limit is the value that the sequence gets "infinitely close" to. This "infinitely close" concept is made precise using infinitesimals.

Here's a simplified example using the function f(x) = x^2. To find the derivative at x = 2 using non-standard analysis:

**Step 1:** Consider an infinitesimal *dx*.

**Step 2:** Evaluate f(2 + *dx*) = (2 + *dx*)^2 = 4 + 4*dx* + (*dx*)^2

**Step 3:** Calculate the difference quotient: (f(2 + *dx*) - f(2)) / *dx* = (4 + 4*dx* + (*dx*)^2 - 4) / *dx* = 4 + *dx*

**Step 4:** Take the *standard part* of the result. The standard part of 4 + *dx* is 4, since *dx* is infinitesimal and can be disregarded.

Therefore, the derivative of f(x) = x^2 at x = 2 is 4. This illustrates how non-standard analysis can simplify calculations.
