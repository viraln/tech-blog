## Revolutionary Aspect #2: The Rise of Non-Local Neural Networks

Non-local neural networks (NNs) represent a significant advancement in deep learning architecture. They seamlessly integrate non-local operations into existing neural networks, allowing them to learn and reason about long-range dependencies without requiring extensive modifications to the underlying structure.

The core building block of a non-local NN is the non-local block, which can be inserted into any layer of a convolutional network. This block computes a response at each position by attending to all other positions in the input feature map. This attention mechanism allows the network to capture long-range dependencies and contextual information effectively.

**How Non-Local Blocks Work:**

1.  **Compute Attention Weights:** The block calculates attention weights between each pair of positions in the input feature map.
2.  **Aggregate Features:** The block aggregates features from all positions, weighted by the attention weights.
3.  **Combine with Original Feature Map:** The aggregated features are combined with the original feature map, resulting in an enriched representation that captures long-range dependencies.
