## What are Multiple State Personas?

Multiple state personas, in contrast to single, static personas, acknowledge the dynamic nature of user behavior.  Instead of representing a single, average user, they illustrate how a single user can behave differently based on varying circumstances.  Think of it as creating several "snapshots" of the same individual within different contexts. This might involve different emotional states (frustrated, excited), goals (learning, completing a task), or technological proficiency levels (beginner, expert). ![A graphic showcasing a single user with multiple "bubbles" representing different states](https://images.unsplash.com/photo-1496144300411-8dd31ce145ba?q=85&w=1200&fit=max&fm=webp&auto=compress)

> **EXPERT TIP:**  Don't confuse multiple state personas with multiple *user* personas.  Multiple user personas represent different *types* of users. Multiple state personas represent the different ways a *single* user type might behave.

## Designing Multiple User Personas: A Step-by-Step Guide

Creating effective multiple state personas requires a structured approach. Here's a practical, step-by-step guide:

1. **Identify Core User Personas:** Begin by defining your primary user personas. Who are your typical users? What are their demographics, needs, and motivations?
2. **Brainstorm State Variations:** For each core persona, brainstorm potential state variations. Consider factors like emotional state (happy, stressed, frustrated), task goals (quick task, complex project), experience level (novice, expert), and technological context (mobile vs. desktop).
3. **Develop Individual State Personas:** Create a separate persona profile for each state variation.  Include details like their goals, motivations, frustrations, and technological proficiency.  ![Example of a multiple state persona template](https://images.unsplash.com/photo-1518451753910-9c0b6285d15a?q=85&w=1200&fit=max&fm=webp&auto=compress)

5. **Iterate and Refine:** Regularly review and update your multiple state personas as you gather more data and gain a deeper understanding of your users.
