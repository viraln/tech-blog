## A Simple Spacetime Script Tutorial Example (Python & GeoPandas)

This simple *spacetime script tutorial* demonstrates how to use GeoPandas to analyze the density of points within a given area.

**Step 1:** Install GeoPandas and its dependencies.

```bash
pip install geopandas
```

**Step 2:** Import the necessary libraries.

```python
import geopandas
import matplotlib.pyplot as plt
from shapely.geometry import Point
```

**Step 3:** Create sample point data with timestamps.

```python
# Sample data (replace with your actual data)
data = {'latitude': [34.0522, 34.0622, 34.0722, 34.0822],
        'longitude': [-118.2437, -118.2537, -118.2637, -118.2737],
        'timestamp': ['2025-01-01 00:00:00', '2025-01-01 01:00:00', '2025-01-01 02:00:00', '2025-01-01 03:00:00']}

# Create a GeoDataFrame
geometry = [Point(xy) for xy in zip(data['longitude'], data['latitude'])]
gdf = geopandas.GeoDataFrame(data, geometry=geometry, crs="EPSG:4326")  # Set coordinate reference system

print(gdf.head())
```

**Step 4:** Create a bounding box (area of interest).

```python
# Define a bounding box (replace with your actual area)
min_lon, min_lat = -118.28, 34.04
max_lon, max_lat = -118.23, 34.09

# Create a polygon representing the bounding box
polygon = geopandas.GeoSeries([Point(min_lon, min_lat), Point(max_lon, min_lat), Point(max_lon, max_lat), Point(min_lon, max_lat), Point(min_lon, min_lat)]).unary_union
bounding_box = geopandas.GeoDataFrame({'geometry': [polygon]}, crs="EPSG:4326")
```

**Step 5:** Perform a spatial join to find points within the bounding box.

```python
# Spatial join
points_within_area = geopandas.sjoin(gdf, bounding_box, predicate='within')

print(points_within_area.head())
```

**Step 6:** Visualize the data.

```python
# Plotting
fig, ax = plt.subplots(figsize=(10, 10))
bounding_box.plot(ax=ax, color='lightgrey')
gdf.plot(ax=ax, marker='o', color='blue', markersize=5)
points_within_area.plot(ax=ax, marker='*', color='red', markersize=10)

ax.set_title('Points within Bounding Box')
plt.show()
```

This example demonstrates a basic spatial join. You can extend this to analyze point density within the area, calculate distances, or perform more complex spatiotemporal analyses.
