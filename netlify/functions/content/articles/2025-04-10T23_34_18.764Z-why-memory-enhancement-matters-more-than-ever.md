## Understanding the Science of Memory

Our brains are incredibly complex, and memory isn't a single process but a multifaceted system.  Understanding how memory works is the first step to improving it.  There are three main types of memory: sensory memory (briefly holding sensory information), short-term memory (holding information for a short period), and long-term memory (relatively permanent storage).  Long-term memory is further divided into declarative (facts and events) and non-declarative (skills and habits) memory.  Improving memory involves strengthening each of these stages.

> **DID YOU KNOW?**  The hippocampus, a seahorse-shaped structure in the brain, plays a crucial role in forming new long-term memories.
