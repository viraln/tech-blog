## 1. Understanding the Wave Function Collapse Analogy

The term "Wave Function Collapse" comes from quantum mechanics, describing the process by which a quantum system transitions from a superposition of multiple possible states to a single, definite state upon measurement or observation. Think of Schrödinger's cat: before opening the box, the cat is simultaneously alive *and* dead (a superposition). Opening the box forces the wave function to "collapse," revealing a single reality – either alive *or* dead.
